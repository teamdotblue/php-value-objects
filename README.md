# team-blue/php-value-objects

Value objects for PHP.

Provides base classes for typed scalar values (`BoolValue`, `IntValue`, `FloatValue`, `StringValue`), enums, lists, date/time values and pattern-based values, plus interfaces like `HasDefault` and `HasExamples` and a `CalcValueObject` abstraction. Used together with [`team-blue/php-exception`](https://github.com/teamdotblue/php-exception) and [`team-blue/php-json-immutable-objects`](https://github.com/teamdotblue/php-json-immutable-objects).

## Installation

```bash
composer require team-blue/php-value-objects
```
